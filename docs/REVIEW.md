## Reference and coverage limits

Consulted upstream Python, Git, Fish, Nano, GitHub CLI and wl-clipboard references
linked in the [manual](../ARSENAL.md#references). The full GNU manual URLs timed
out in the web fetcher; local `expand --help` and direct disposable checks were
used for the conversion behavior. Keep the GNU canonical links, but do not count
them as successfully fetched in this review. The public issues-page web fetch also
failed; repository metadata confirms issues are enabled, not browser accessibility.

Nano shortcuts were checked against its manual, not every keyboard layout or
interactive binding mode. Wayland clipboard interaction and the example's
GitHub authentication/push/PR flow were not executed as documentation tests.
Filesystem examples assume an ordinary directory controlled by the reader;
symlinks, special files, concurrent writers and platform-specific variants are
not exhaustively tested. Indentation changes can still alter program meaning.

The project intentionally has no added CI pipeline, package manifest or test
framework. Recheck affected examples when editing them, following
[CONTRIBUTING.md](../CONTRIBUTING.md). This dated review is evidence of the scope
above, not an evergreen guarantee. No customer outcomes, adoption metrics or
professional experience claims have been added.
