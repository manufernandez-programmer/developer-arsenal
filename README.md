# Developer Arsenal

A practical developer encyclopedia and quick-reference manual for everyday development tools.

Developer Arsenal is designed to work in two ways:

- ⚡ Quick Mode — find a command, remember how it works, and keep working.
- 🎓 Learning Mode — understand commands through examples, visual breakdowns, and explanations.

## What's Inside

Developer Arsenal currently covers:

- Terminal navigation and file management
- Search, pipes, redirection, and shell operators
- Python basics and syntax checking
- Git and GitHub workflows
- Nano
- Fish shell
- Common developer utilities
- Practical troubleshooting patterns

## Philosophy

The goal is simple:

Need to remember something? Find it and keep working.

Don't understand something? Break it down, understand what happened, then return to building.

Technical accuracy comes first. Humor comes second.

## Status

Developer Arsenal is an evolving reference built from real development workflows and practical problems.

New tools and concepts can be added as the arsenal grows.
